# TF2 Fighter — PS3 build kit (prototype 0.1)

Это проект для удалённой сборки через GitHub Actions. Он использует официальный открытый набор исходников PSL1GHT как основу RSX-рендеринга, а затем заменяет демонстрационную сцену на простой файтинг.

## Что входит в прототип

- две локальные позиции игрока, управление двумя подключёнными DualShock-контроллерами;
- движение влево/вправо, прыжок, гравитация и вылет за край арены;
- ближняя атака, дальний снаряд с перезарядкой;
- Brutal Mode с усиленными атаками;
- ульта с короткой сценой из нескольких ударов и отбрасыванием;
- шкалы урона, метр, три жизни и перезапуск матча;
- простая арена с визуальной иллюзией движущегося поезда.

Графика пока сделана из цветных 3D-блоков — моделей Scout и других персонажей TF2 здесь ещё нет. Это именно первый нативный PS3 прототип, не законченная игра.

## Как получить сборку, используя телефон

Для автоматической компиляции нужен аккаунт GitHub и доступ к GitHub Actions. На самом телефоне устанавливать компилятор не нужно.

1. Скачай и распакуй этот архив на телефоне.
2. На GitHub создай новый **пустой** репозиторий с именем `tf2fighter-ps3`.
3. Загрузи в репозиторий содержимое архива, включая скрытую папку `.github` и файл `.github/workflows/build-ps3.yml`. Убедись, что GitHub показывает workflow в разделе **Actions**.
4. Открой **Actions → Build TF2 Fighter for PS3 → Run workflow**. Если запуск разрешён и workflow прошёл успешно, открой завершённый запуск и скачай артефакт `TF2-Fighter-PS3-build`.
5. Внутри артефакта будет `TF2-Fighter-Prototype.pkg`, если компиляция завершилась успешно. Скопируй `.pkg` в корень USB-флешки FAT32 и установи через уже имеющийся у тебя **Package Manager → Install Package Files → Package Directory**.

Если пункт `Actions` не появился после загрузки, проверь, что путь к файлу написан точно: `.github/workflows/build-ps3.yml`. GitHub Actions может требовать включения владельцем репозитория.

## Важно

- Я не могу из этой среды запустить GitHub Actions от твоего имени или проверить файл `.pkg` на твоей консоли.
- Поэтому ZIP этого набора **не является готовым `.pkg`**. Настоящий пакет появится только после успешного выполнения сборки в GitHub Actions.
- Первый запуск может выявить несовместимость upstream-примера с текущей версией toolchain. Если workflow завершится ошибкой, пришли сюда скриншот или текст ошибки из шага, и я исправлю файлы проекта.
- Прототип не содержит кода для обхода защиты консоли и не меняет прошивку. Он использует стандартный процесс сборки homebrew-пакета PSL1GHT.
